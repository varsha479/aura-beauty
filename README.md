# Glowup Studio

A modern full-stack application for glamorous transformations.

## Project Structure

```
glowup-studio/
│
├── client/        (Frontend React)
├── server/        (Backend Node)
└── README.md
```

## Setup

### Client (React)
Navigate to `client/` directory and follow setup instructions.

### Server (Node)
Navigate to `server/` directory and follow setup instructions.

## Getting Started

1. Install dependencies in both client and server directories
2. Configure environment variables
3. Start the development servers
